## About

`HTML-Projects` is a collection of browser-based projects created by **Taha Hassarki**, focused on interactive games, creative experiments, and practical web development.

## Projects

| Project | Description | Technologies |
|---|---|---|
| [JUMONG: DRAGON PATH](./JUMONG-DRAGON-PATH/) | Persian 2D action-adventure browser game with story chapters, combat, and touch controls. | HTML, CSS, JavaScript, Canvas, Web Audio |
| [THE LAST CROWN — RISE OF EMPIRES](./THE-LAST-CROWN/) | Persian offline 4X strategy game featuring realm management, exploration, economy, research, warfare, and diplomacy. | HTML, CSS, JavaScript, LocalStorage, Web Audio |
